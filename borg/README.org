#+title: Borg package sources

All package sources, including Borg itself, live here as Git submodules pinned
to exact commits.  Borg runs in *primary mode* and activates these drones at
startup.  Package.el does not activate or install packages.

Don't add or clone packages here by hand; use =M-x borg-assimilate=
(for a new package) or =M-x borg-build= (after an intentional source update)
so that the submodule, autoloads and byte-code stay consistent.  Updates are
manual: change a drone's checked-out commit, validate it, and commit the new
gitlink.  Neither startup nor Borg automatically upgrades packages.

For a fresh clone, run =make bootstrap-borg= followed by =make bootstrap=.
The first command makes Borg available; the second initializes each recorded
submodule and builds its autoloads and byte-code.  Borg honours
=borg.drones-directory= (set in =.borgconfig=) because this directory exists.
The primary-mode bootstrap follows the [[https://github.com/emacscollective/borg/blob/main/docs/borg.org][official Borg manual]], with =borg/=
selected in place of its default =lib/=.
