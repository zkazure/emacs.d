#+title: Emacs Configuration

My personal Emacs configuration.

* Get Started

#+begin_src sh
  git clone --recurse-submodules https://github.com/zkazure/emacs.d.git ~/.emacs.d
  cd .emacs.d/
  git submodule update --init --recursive
  make autoloads
#+end_src
